BHSD nnU-Net Project

This project contains baseline nnU-Net v2 pipelines for BHSD CT hemorrhage segmentation, including 2D, 3D, and custom 2.5D extensions for both legacy 3-slide and newer CSAM-style models.

Overview

The dataset is BHSD CT data with anisotropic spacing and relatively large z-spacing. Standard nnU-Net v2 2D and 3D pipelines are supported, along with custom 2.5D trainers that extend the 2D pipeline without changing the original loss or optimization setup.

Available Pipelines

  • 2D baseline: standard single-slice nnU-Net v2 training.
  • 3D baseline: standard full-resolution 3D nnU-Net v2 training.
  • 3-slide baseline: stacked adjacent slices used as multi-channel 2D input.
  • CSAM: center-guided slice-attention models with bottleneck or multi-scale fusion.
