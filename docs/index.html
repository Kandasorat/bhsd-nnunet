BHSD nnU-Net Project

This project contains baseline nnU-Net v2 pipelines for BHSD CT hemorrhage segmentation, including 2D, 3D, and a minimal 2.5D extension based on stacked adjacent slices.

Overview

The dataset is BHSD CT data with anisotropic spacing and relatively large z-spacing. Standard nnU-Net v2 2D and 3D pipelines are supported, and a custom 2.5D trainer has been added to extend the 2D pipeline without changing the original loss, optimizer, or architecture depth.

Available Pipelines

  • 2D baseline: standard single-slice nnU-Net v2 training.
  • 3D baseline: standard full-resolution 3D nnU-Net v2 training.
  • 2.5D baseline: stacked adjacent slices used as multi-channel 2D input.

2.5D Extension

The 2.5D extension reuses the standard 2D preprocessing pipeline and changes only the slice loading behavior inside the dataloader.

  • 3-slice version: [z-1, z, z+1]
  • 5-slice version: [z-2, z-1, z, z+1, z+2]
  • Target label: center slice only
  • Boundary handling duplicates edge slices when needed

Baseline Commands

2D

powershell -ExecutionPolicy Bypass -File .\scripts\nnunet_2d_baseline.ps1

3D

powershell -ExecutionPolicy Bypass -File .\scripts\nnunet_3d_baseline.ps1

2.5D

powershell -ExecutionPolicy Bypass -File .\scripts\nnunet_25d_baseline.ps1

Trainer Commands

3-slice 2.5D trainer

nnUNetv2_train Dataset001_BHSD 2d 0 -tr nnUNetTrainer_25D

5-slice 2.5D trainer

nnUNetv2_train Dataset001_BHSD 2d 0 -tr nnUNetTrainer_25D_5Slice

Project Files

  • scripts/: baseline PowerShell launch scripts
  • nnunet25d/: custom 2.5D dataloader, trainers, and install script
  • nnUNet_data/: local dataset, preprocessing outputs, and results
