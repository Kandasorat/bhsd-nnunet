# AWS G5 Deployment Guide

This document describes the intended Linux deployment workflow for the BHSD nnU-Net research pipeline.

## 1. Prepare the machine

Install the following first:

- NVIDIA driver
- CUDA-compatible PyTorch support
- Miniconda or Anaconda
- git

## 2. Clone the repository

```bash
git clone <your-repo-url>
cd bhsd-nnunet
```

## 3. Create the environment

```bash
bash scripts/setup_env.sh
conda activate bhsd-nnunet
```

## 4. Set nnU-Net paths

```bash
export PROJECT_ROOT="$(pwd)"
export nnUNet_raw="$PROJECT_ROOT/nnUNet_data/nnUNet_raw"
export nnUNet_preprocessed="$PROJECT_ROOT/nnUNet_data/nnUNet_preprocessed"
export nnUNet_results="$PROJECT_ROOT/nnUNet_data/nnUNet_results"
```

## 5. Install custom 2.5D extensions

```bash
python scripts/install_extension.py
```

## 6. Run experiments

Examples:

```bash
bash scripts/preprocess.sh baseline_2d
bash scripts/train.sh baseline_2d
bash scripts/train.sh baseline_25d_3slide
bash scripts/infer.sh baseline_3d
bash scripts/evaluate.sh baseline_3d
```

Or run the whole configured pipeline:

```bash
bash scripts/run_experiment.sh baseline_2d
```

## 7. Reproducibility checklist

- keep configs under `configs/`
- never edit results manually
- export tables and figures to `results/`
- preserve metadata JSON files generated by `run_experiment.py`
